# Daily Expense Tracker

A modern PHP/MySQL expense tracking application built with MVC architecture.

## 🚀 Features

- ✅ User authentication and registration
- ✅ Add, edit, and delete expenses
- ✅ Dashboard with expense statistics
- ✅ Multiple report types (datewise, monthwise, yearwise)
- ✅ Responsive design with Bootstrap
- ✅ MVC architecture for clean code organization

## 🛠️ Tech Stack

- **Backend:** PHP 8.2, MySQL 8.4
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Development:** DDEV (Docker-based local development)
- **Architecture:** MVC Pattern
